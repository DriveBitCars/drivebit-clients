# Акты осмотра — крупные миниатюры и fullscreen-просмотр фото

Дата: 2026-09-06  
Статус: одобрено  
Платформы: Web + Mobile  
Ветка: `fix/inspection-act-photo-fullscreen`

## Проблема

В UI акта осмотра фотографии показываются миниатюрами 72×72 без реакции на
клик. Для проверки повреждений и приборной панели этого мало: нельзя быстро
разглядеть снимок.

## Цели

- Увеличить миниатюры фото в секциях акта (авто / панель / прочие).
- По клику открывать фото на отдельном полноэкранном экране.
- Сохранить удаление фото на списке акта (не в fullscreen).
- Web и Mobile ведут себя одинаково по смыслу.

## Не входит в задачу

- Свайп/карусель между фото в fullscreen.
- Pinch-zoom / жесты масштаба.
- Переиспользование маршрута `/car-photos-gallery`.
- Изменение API загрузки/удаления фото.

## Решение

**Сетка крупных превью + отдельный fullscreen-маршрут/экран на клик.**

### Список фото в акте

- Раскладка: CSS/Compose grid с `minmax(160px, 1fr)` (на узком экране обычно
  2 колонки).
- Высота миниатюры: общая константа `INSPECTION_ACT_PHOTO_THUMBNAIL_PX = 200`
  в Network (web: px, mobile: dp), `object-fit` / `ContentScale.Crop`,
  скругление 8px.
- Клик по изображению открывает fullscreen; кнопка «Удалить» остаётся под
  превью и не открывает просмотр.

### Fullscreen

- Чёрный фон, изображение по центру, `contain` / `ContentScale.Fit`.
- Закрытие: Web — `history.back()` («Назад»), Mobile — `navigator.pop()` через
  top bar.
- Пустой/отсутствующий URL: короткое сообщение «Фото не указано» / аналог.

### Web-маршрут

- Путь: `/inspection-act/photo?url=<encoded>`.
- Хелперы в Network: `inspectionActPhotoPagePath`, `isInspectionActPhotoPath`.
- Роутинг в account-бандле рядом с актом; meta-path нормализует
  `/inspection-act*`.

### Mobile

- Voyager-экран `InspectionActPhotoScreen(photoUrl, title)`.
- Push из секции фото акта с заголовком секции.

## Тесты

- Unit: путь `/inspection-act/photo` распознаётся, акт без `/photo` — нет.
- Существующие тесты акта и загрузки фото не ломаются.

## Критерии готовности

- На акте миниатюры заметно крупнее 72px и читаемы.
- Клик по фото открывает fullscreen на Web и Mobile.
- «Назад» возвращает к акту.
- «Удалить» работает с списка и не зависит от fullscreen.
