## Как протестировать

### Вариант 1: Через форму в браузере

1. Откройте http://localhost:8080
2. Войдите в систему (нужен номер телефона и OTP код)
3. Перейдите на `/list-your-car` или начните процесс создания автомобиля
4. Заполните все поля формы:
   - Выберите марку автомобиля
   - Выберите модель
   - Выберите тип кузова
   - Выберите тип привода
   - Выберите тип двигателя
   - Введите объем двигателя
   - Введите год выпуска
   - Введите количество мест
   - Введите VIN код
5. Нажмите "Продолжить" на странице ввода количества мест
6. Автомобиль будет создан через POST `/Car/my`
7. Перейдите на `/my-cars` и проверьте, что автомобиль появился в списке

### Вариант 2: Через консоль браузера (после авторизации)

1. Войдите в систему через браузер
2. Откройте консоль разработчика (F12)
3. Выполните скрипт из файла `test-create-car.js`:

```javascript
// Скопируйте содержимое test-create-car.js в консоль
// Или выполните:
createTestCar()
```

4. Проверьте результат в консоли
5. Перейдите на `/my-cars` и проверьте список

### Вариант 3: Через API напрямую (с токеном)

```bash
# Получите токен после авторизации
TOKEN="your_token_here"

# Создайте автомобиль
curl -X POST "https://drivebit.my/api/Car/my" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "brandId": 1,
    "modelId": 1,
    "bodyType": "Sedan",
    "driveType": "Front",
    "engineType": "Gasoline",
    "engineVolume": 2.0,
    "productionYear": 2020,
    "seatsCount": 5,
    "winCode": "TEST123456789"
  }'

# Проверьте список
curl -X GET "https://drivebit.my/api/Car/my" \
  -H "Authorization: Bearer $TOKEN"
```

## Проверка результата

После создания автомобиля:

1. ✅ Автомобиль должен быть создан (POST запрос вернет `CarResponse` с `id`)
2. ✅ При переходе на `/my-cars` автомобиль должен появиться в списке
3. ✅ В списке должны отображаться:
   - Фото автомобиля (если загружены)
   - Название (бренд и модель)
   - Год выпуска
   - Количество мест

## Технические детали

- **Endpoint**: `POST /api/Car/my`
- **Авторизация**: Требуется (Bearer token)
- **Request body**: `CarCreateRequest`
- **Response**: `CarResponse` с `id` созданного автомобиля
- **Метод в коде**: `carService.createCar(request)`
